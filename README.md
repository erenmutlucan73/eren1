# Mutlucan Tarım İşletmeleri

PHP tabanlı kurumsal tarım web sitesi.

## Render Deploy

Render'da Web Service oluştururken repo kökünde `Dockerfile` bulunduğu için Docker deploy kullanılabilir.

Ana dosya:

```text
index.php
```

Admin panel:

```text
admin.php
```

Admin panel ilk açılışta kullanıcı adı ve şifre oluşturmanızı ister. Hazır varsayılan şifre yoktur.
